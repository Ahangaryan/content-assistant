## درباره

این افزونه وردپرس را به یک API سازگار با OpenAI وصل می‌کند و نتیجه را همان‌جایی می‌آورد که نوشتن اتفاق می‌افتد: داخل ویرایشگر نوشته، در پنلی کنار صفحه یا متاباکسی در ویرایشگر کلاسیک. پیشنهادها و بازنویسی‌ها کنار محتوای تو ظاهر می‌شوند و تا تأیید نکنی چیزی ذخیره نمی‌شود.

جز ویرایشگر، دو بخش کارهای روزمره را پوشش می‌دهند: زمان‌بندی روزانه که خودش منتشر می‌کند، و ویرایشگر گروهی که پست‌ها را می‌گردد و جاهای خالی را پر می‌کند.

## امکانات

### دستیار ویرایشگر

- **پنل کنار صفحه** در ویرایشگر بلوک و **متاباکس** در ویرایشگر کلاسیک.
- پیشنهاد عنوان، تولید متن بدنه، پیشنهاد خلاصه، یا بازنویسی فقط بلوک انتخاب‌شده.
- اجرای دستور دلخواه روی هر فیلد، از جمله فیلدهای سفارشی که در پست پیدا می‌شوند.
- بررسی سئو با امتیاز و پیشنهاد مشخص، سازگار با Yoast SEO، RankMath و All in One SEO.
- هر نتیجه اول پیش‌نمایش است؛ محتوا فقط بعد از تأیید تو تغییر می‌کند.
- دکمهٔ اختیاری در نوار مدیریت، تا پنل از هر صفحهٔ ادمین یک کلیک فاصله داشته باشد.

### انتشار زمان‌بندی‌شده

- یک برنامه روزانه برای هر پست‌تایپ: تعداد مطلب در روز، پخش‌شده در یک بازه زمانی یا در ساعت‌های مشخص.
- فهرست موضوعات، زبان محتوا و وضعیت انتشار برای هر برنامه.
- اسلات‌های امروز همان‌طور که پر می‌شوند دیده می‌شوند و هر برنامه را می‌توان فوری اجرای آزمایشی کرد.
- اجرا با WP-Cron، هر پنج دقیقه.

### ویرایش گروهی

- فیلتر پست‌هایی که محتوا، عنوان، خلاصه، تصویر شاخص یا توضیح متا ندارند.
- تولید یا اصلاح آن‌ها در یک گذر، با نوار پیشرفت و لاگ رویداد.
- فاصلهٔ قابل تنظیم بین درخواست‌ها، تا مصرف API قابل پیش‌بینی بماند.

### تنظیمات و مصرف

- کلید API، آدرس سرویس، مدل، دما و سقف توکن.
- زبان محتوا و زبان رابط، مستقل از هم.
- تست اتصال که پاسخ سرویس را بلافاصله نشان می‌دهد.
- کلید API رمزنگاری‌شده ذخیره می‌شود.
- کارت‌های مصرف برای فراخوانی‌ها، توکن‌ها و مطالب تولیدشده، به‌همراه لاگ رویدادهای قابل فیلتر.

## پیش‌نیازها

| | |
|---|---|
| وردپرس | ۵٫۸ یا جدیدتر (تا ۶٫۷ آزمایش شده) |
| PHP | ۷٫۴ یا جدیدتر |
| API | هر سرویس سازگار با OpenAI و یک کلید معتبر |
| کرون | WP-Cron، یا یک کرون سیستمی واقعی برای سایت کم‌ترافیک |

## نصب

1. پوشهٔ افزونه را در `wp-content/plugins/` کپی کن و فعالش کن.
2. به **هوش مصنوعی برای وردپرس ← تنظیمات** برو، کلید API و مدل را وارد کن و تست اتصال را بزن.
3. اگر انتشار زمان‌بندی‌شده می‌خواهی، در **زمان‌بندی** برای هر پست‌تایپ یک برنامهٔ روزانه بساز.
4. برای اصلاح محتوای موجود، **ویرایش گروهی** را باز کن و فیلترهای مورد نظرت را بگذار.

## پرسش‌های پرتکرار

**مطلب تولیدشده کجا ذخیره می‌شود؟**
در همان پست‌تایپی که انتخاب کرده‌ای، با وضعیتی که در تنظیمات یا در برنامه گذاشته‌ای. پیش‌فرض پیش‌نویس است.

**چیزی بدون تأیید من تغییر می‌کند؟**
نه. دستیار همیشه اول پیش‌نمایش می‌دهد و اعمال کردن آن یک اقدام جداست.

**زمان‌بندی به بازدید نیاز دارد؟**
WP-Cron با بازدید اجرا می‌شود. برای سایت کم‌ترافیک، یک کرون سیستمی هر پنج دقیقه روی `wp-cron.php` تنظیم کن.

**فیلدهای سفارشی پشتیبانی می‌شوند؟**
بله. فیلدهای شناسایی‌شده در پست، از جمله فیلدهای سفارشی، با دستور دلخواه قابل هدف‌گیری هستند.
